## Oracle design (exact mechanics)

- **Imports:** `CENSUS_DOC_PATH`, `CENSUS_ROWS`, `INVARIANT_CENSUS` + the four types from `@/backend/db/test/logic/invariants/invariant-census.catalog` — per 2.1 contract item 1 (this import also resolves the transient knip "no importer" state noted in 2.1 carry-forward #6).
- **Doc side:** regex `/INV-[A-Z]+\d+/gu` into a `Set` (67 unique today); corpus sanity floor `MIN_DOC_INV_IDS = 60` (contract item 2). A separate non-global twin pattern validates single ids (a `/g` regex's `.test()` is lastIndex-stateful — hazard avoided).
- **Bijection:** `diffInvIdBijection(docIds, censusIds)` — pure, injectable, sorted outputs in BOTH directions: doc ID missing from census fails; census ID missing from doc fails (contract item 2).
- **Binding resolution (contract item 3):** `resolveBinding(readFileAt, binding)` with an injectable file view. `testPath` is repo-root-relative POSIX resolved via `join(process.cwd(), …)` — the `audit-census-drift.test.ts:63` precedent (run-test.ts pins child cwd to PROJECT_ROOT; test:db workers inherit repo-root cwd). `testName` is a plain substring check (`content.includes(testName)`). Results: `ok | unsafe-path | missing-file | name-not-found`, each with a one-line human diagnosis naming the row's exact defect.
- **`docLine`:** deliberately NOT asserted anywhere (contract item 4 — 6.1's `†` annotations will reflow lines). The bijection is ID-set-based; `docLine` is metadata.
- **PIN rows (contract item 5):** every `PIN-APP-LAYER+DOC-DRIFT` row must carry a `ledgerRef`, and EVERY `ledgerRef` on ANY row must be well-formed (`/^D-\d{3}$/u`) and live in `ai/plans/milestone_4/state_machine_invariant_verification/deferred-items.md` (matched as `` `| ${ref} ` `` — the ledger table's ID column). The only-PIN direction is NOT asserted — TV7 (NEW-PROBE) legitimately carries D-401 too; today 7 rows carry refs, all live.
- **Pinned totals (contract item 7):** 67 rows · 12 machine keys (pinned key list `MACHINE_KEYS`, set-equality with `Object.keys(INVARIANT_CENSUS)`) · per-machine S8/TV7/A4/B8/W8/U5/P4/PAY7/HW4/PR3/E6/PC3 · verdicts 45/18/4 (closed value set) · dispositions 32/24/5/6 (the four legal values) · 16 `docDrift` rows · ≥1 binding per row · every row sits under its declared machine key and the flat view is the exact union of the groups.
- **Negative self-test (C5):** 7 tests, all passing BECAUSE detection fires — fake doc ID → `missingFromCensus: ["INV-ZZ9"]` (and nothing else); phantom census ID → `missingFromDoc`; phantom citation on an existing file → `name-not-found`; nonexistent file → `missing-file`; `../`-escape and absolute paths → `unsafe-path` (never read); a well-formed binding → `ok` against the injectable view; dead ledger ref `D-999` rejected, live PIN refs accepted.
