## Design decisions (recorded for reviewers)

1. **B8 needs no subscription fixture** — the trial branch of `debitBookingLadder` returns before subscription state is ever probed (`session-lifecycle.booking.ts:133-135`), so the ordering cell books on the trial lane alone; adding a subscription would make the case a duplicate of the pre-existing in-window ladder tests without strengthening the ordering proof.
2. **B3 models the post-cancel state directly** (positive lane + a `Cancelled` subscription row) rather than driving an admin cancel mid-test — the cancel path's balance-preservation is already pinned by the admin-lifecycle suites (bound by reference); the NEW semantics under test are the zeroing guard's active/pending anti-join treating the cancelled row as non-covering. The second same-lane subscription supplies the "later covering sweep".
3. **A1's ordering-1 terminal row (online + uncertified) is the LEGAL serialization**, not a gate bypass — the availability write committed against the locked certified value; the demote serialized after it. The test says so in domain language and pins the re-assertion (follow-up toggle FORBIDDEN, zero writes) so the terminal state can never be mistaken for a bypass. The INV-A1 census row carries no `†` docDrift (the shipped behavior matches the doc statement), so no doc annotation is owed.
4. **A1's race leg asserts outcome-conditioned consistency**, not one fixed terminal state — a race oracle must accept either serialization while proving the invariant property (an Available write only ever lands against a certified locked value; the gate denies otherwise). This mirrors the pre-existing sweep-vs-debit race test's `typeof debited === "boolean"` posture.
5. **E5's composite grades sit below the 60 threshold and beyond the 14-day staleness window with wide margins** (45 avg; 15-day-old newest write) so the flag leg is deterministic under clock jitter, and the both-tracks/single-track homework pair proves the per-entry track objects (including the null opposite track) in the same snapshot as the report, the count, and the flag.
