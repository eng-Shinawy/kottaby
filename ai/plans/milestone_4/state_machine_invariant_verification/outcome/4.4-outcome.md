## Design decisions (recorded for reviewers)

1. **P3 uses the caller-owned transaction path** (`completeSessionWithReceipt` with `tx`) — the same idiom the file's own `provisionCompletedSession` uses for σ1/σ2: the receipt returns UNPUBLISHED and the pin deliberately never publishes it, so the spied-transport window stays closed by design and `publishCount === 0` is the honest observable for "the completed flip dispatches nothing". The wave's PREPARED recipient set is asserted from the returned receipt (`[studentS1]`, parent absent), which is the non-vacuous half: it proves the flip's only emission never targets the parent even though the child is linked at completion time. Publishing the receipt through the spy would have made the fixed census title ("zero spied publishes") false; running the flow-owned path would have pushed a real prompt through the unspied default transport (rule-5 violation).
2. **P3 reuses the linked child S1 rather than a new student** — keeps the pin inside the existing tracked cast (no cast/afterAll changes needed; `notifications.user_id` is `ON DELETE CASCADE` to `users`, so the cascading teardown covers every side-effect row); the fresh lane credit is a committed fixture write re-arming the booking gate (S1's trial lane was consumed by σ1's booking).
3. **A4 is self-contained (per-step fixture R)** rather than reusing the shared L cast from steps 4–7 — the pin owns its whole online window inside one test (toggle → lock → stale → restore → sweep), which is rerun-isolated and does not depend on step-4 state; the shared-L walkthrough (step 7) remains the pre-existing observational leg and was not re-authored. The new `readTeacherMarker` oracle pins BOTH the capture (`true` while locked) and the consumption (`null` after the release) — the marker-gated half the census title names.
4. **A4's sweep count follows the file's drain-then-count discipline** (`drainOnlinePopulation()` before the fixture goes online — the sweep predicate is global, so only what the step itself created is counted; identical exposure to steps 3/8/9/10, all green at baseline).
5. **Teachers DIAGRAMS.md carries ONLY the inactivity-sweep section** — the task text scopes the new file to "the section for this journey"; the domain's other ten pre-existing journeys still lack sections (see carry-forward #1).
