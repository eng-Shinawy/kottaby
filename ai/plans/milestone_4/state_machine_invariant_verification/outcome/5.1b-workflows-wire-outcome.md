## 3. The Lessons Role-Matrix pg-pool diagnosis (the task's explicit question)

**Root cause: NOT pool exhaustion, NOT sibling contention — a deterministic mid-process pool kill.**

`bun test` runs all wire-tier files sequentially in ONE process with a shared module registry (one shared `db`/pg pool). `admin-session-governance.mutation.test.ts`'s `afterAll` calls `await closePool()` (`:344`; the query suite's `afterAll` does the same at `:347`, committed at HEAD in `6cb77a32` — pre-existing). The full-suite log shows `[WARN] [db] pool closed` immediately after that suite's last test, and the **very next file** (`admin-session-governance.query.test.ts`) dies at its first DB touch with `Cannot use a pool after calling end on the pool` — followed by 65 such errors across every later DB-touching file. `lesson.roles.test.ts` (26 tests) loses exactly 23; the 3 survivors are the pure-SDL cells that never touch `db`.

**Proof chain:**
1. **Log position:** the `[WARN] [db] pool closed` line sits at the boundary between the two suites; the first pool error's stack is the next file's first query.
2. **Isolation:** `run-test.ts backend/graphql/test/lesson.roles.test.ts` → **26 pass / 0 fail** (post phone-fix); `run-test.ts backend/graphql/test/teacher-matching.integration.test.ts` → **2 pass / 0 fail, twice** (this plan's file).
3. **Two-file probe** (`KOTTABY_TEST_RUNNER_OK=1 bun --env-file=.env.test test admin-session-governance.mutation.test.ts lesson.roles.test.ts`, output at `/tmp/m4-smi-poolkill-probe.log`): `[WARN] [db] pool closed` after the mutation suite, then **exactly the 23 lesson pool reds** — a perfect minimal reproduction.
4. **Contention ruled out:** identical 70-fail sets in two full runs taken while the sibling `test:db` agent was active; the failures are positional (alphabetical order), not load-dependent.

The baseline's 46-fail Lessons cluster is the same mechanism (fewer files existed then, so the victim list differed). **Disposition: ledger row D-415** (glyph discipline verified after edit: `❌|⚠️` grep = 2, exactly the legitimately-blocked D-409/D-410 cells).
