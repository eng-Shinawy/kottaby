## Module Contract (as built — exact signatures)

```ts
export interface QueryCountSnapshot { total: number; byFingerprint: ReadonlyMap<string, number> }
export interface QueryCountHandle {
  snapshot(): QueryCountSnapshot
  deltaSince(snapshot: QueryCountSnapshot): number
  uninstall(): void
}
export class QueryCounterError extends Error {}
export const FINGERPRINT_PREFIX_LENGTH = 120
export const UNRECOGNIZED_QUERY_FINGERPRINT = "<unrecognized>"
export function installQueryCounter(): QueryCountHandle
```

### Semantics (binding for all consumers)

- **Patch target:** `Client.prototype.query` ONLY. Fingerprint = whitespace-collapsed first-120-chars SQL prefix; **binding-parameter values are never fingerprinted** (secret hygiene AND correct N+1 grouping — the same statement with different params groups to one fingerprint). Config-object queries (`{ text, values }`) and submittable-style objects (`{ submit, text }`) are extracted; anything else (null config pg rejects, numbers, empty objects) lands in the `<unrecognized>` fingerprint.
- **Counting:** every `query()` invocation is recorded synchronously at entry, BEFORE delegation — including invocations the underlying client rejects synchronously (documented: a harness bug then fails loudly rather than hiding in a count delta). Error passthrough is exact: the base method's thrown error object propagates unchanged.
- **Double install throws** (`QueryCounterError`, "already installed" — single-owner discipline); **double uninstall is an idempotent no-op** (safe for `try/finally` cleanup paths). Asymmetry is deliberate and tested.
- **Re-install after uninstall:** fresh zero-state handle; the OLD handle freezes at its final count and never observes the new window (handle-scoped state — no cross-window contamination).
- **Snapshot discipline:** `snapshot()` returns a defensively-copied `Map` (mutating a taken snapshot cannot touch the live counter — runtime-proved) and is immutable-in-time; `deltaSince(s)` is pure arithmetic on this handle's state.
- **Uninstall restoration:** `Object.defineProperty(Client.prototype, "query", originalDescriptor)` — the FULL captured descriptor (value identity + flags), not a bare assignment.

### Design decision (SR-reconciled)

The SR checklist suggested "try/finally in install" for error-path safety. Instead the module is **validation-first + assignment-after**: every throw happens before any mutation, `Object.defineProperty` applies atomically (on failure the property is unchanged), and `activeHandle` is assigned only after the patch succeeds. A failure therefore CANNOT leave a patch or half-installed state — with zero dead defensive branches. Tier-4 test proves it: a reversible `Object.defineProperty` interception makes the patch step throw, and a subsequent install succeeds (no active-state leak).

## Carry-Forward Knowledge (for Tasks 5.3 and 6.1)

1. **The K-query-count regression pattern** future tasks must use:
   ```ts
   const counter = installQueryCounter();          // throws if one is already active
   const before = counter.snapshot();
   // … measured operation (service call / page load) …
   const roundTrips = counter.deltaSince(before);  // assert roundTrips <= K (K = 6, plan Component 8)
   counter.uninstall();                            // exact descriptor restoration
   ```
   Wrap in `try/finally` with `counter.uninstall()` in `finally` — uninstall is idempotent, double-call safe.
2. **`byFingerprint` is the N+1 lens:** the 3N+1 before/after evidence (§6 item 6.5) can show per-statement counts; the SAME statement executed N times appears as one fingerprint with count N. Differences beyond the first 120 chars intentionally collapse — don't rely on long-SQL differentiation.
3. **Bun/JSC quirk (discovered):** `Client.prototype`'s class `prototype` property is `{writable: false}` in Bun — prototype-OBJECT swaps are impossible; property-level defineProperty remains the only patch seam. Any future "make the patch fail" test must use a scoped `Object.defineProperty` interception, not a prototype swap.
4. **pg-pool success callbacks receive `undefined`, not `null`** (`cb(undefined, res)` — `node_modules/pg-pool/index.js:479`); error callbacks receive the error instance. Assert with `toBeUndefined()`.
5. **Lint learnings added:** bare `toSorted()` without a comparator trips `sonarjs/no-alphabetical-sort` (extends 1.1's `toSorted`-over-`sort` learning — comparators required for strings); `void expr` where expr is already `void`-returning trips `no-meaningless-void-operator`; bun:test `toBe` is contravariant on overloaded pg method types — widen received values through an `unknown`-typed helper before `expect(...).toBe(...)`.
6. **Failure-injection is always reversible via:** `Reflect.deleteProperty` (configurable data property) and accessor-property swaps (configurable) — never via `configurable: false` or `Object.freeze` (both irreversible and would permanently brick the shared prototype for the whole test process).
