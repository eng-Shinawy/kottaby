- **Literally, no Materialize node wraps `teacher` anywhere.** A decision-test walk of ALL 24 matching statements (12 registry entries × count+page) in the retained artifacts (`logs/perf/2026-10-09T10-57-45_analyze-queries/explain/`) finds `inside_materialize: false` for every teacher scan node. There is no EXPLAIN case: the eligibility predicate matches **100% of seeded teacher rows** (`Seq Scan on teacher … Filter: (is_online AND is_approved)`, actual rows **2001 of 2001** — every seeded teacher is online+approved by 2.1 construction), so a btree on `(is_online, is_approved)` would match the whole table and never beat a seq scan at this data shape; the min-rating variant's teacher scan runs at a 1-row estimate / 0.6ms actual — no cost case for `teacher(average_rating)`. D9's rationale is explicit: "every added index has a ticket clause or an EXPLAIN case; **no folklore indexes**."
