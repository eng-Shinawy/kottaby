## CLI Contract (exact — binding for 4.2)

```text
bun --env-file=.env.test scripts/perf/bench-matching.ts
  --volumes <csv>   comma-separated distinct integers ≥ 0, default "100,500,2000"
                    (stored/echoed/executed DESCENDING: 2000, 500, 100; input order free;
                    duplicates rejected; 0 = the zero-eligible window)
  --samples <n>     default 30   (0..100,000; 0 samples make latency gates fail closed)
  --warmup <n>      default 5    (0..100,000; warmup durations never recorded)
  --gate-ms <n>     default 200  (1..3,600,000; strict p95 budget)
  --self-check      boolean mini-run: 1 cell (live census volume × rating-desc × plain),
                    3 samples / 1 warmup, NO window flips, NO gates
```

- Unknown `--flag` → stderr (unknown list once each + accepted flags) + **exit 2** before the guard. Missing value / non-integer / out-of-range / empty csv token → exit 2. Stray non-`--` tokens are flag values, ignored (stub-compatible). Repeated flags: last wins.
- **Exit codes:** 0 = every gate passed (self-check: gate-free run completed) · 1 = a gate FAILED or runtime failure · 2 = usage refusal, guard refusal, unusable seed (missing/incomplete/identity-less manifest), or volume headroom refusal.

## Matrix, Volume, Gate, and Oracle Semantics (exact — binding for 4.2)

- **Matrix** (specs REQ-2.2): volumes × sorts {`RATING_DESC`→`rating-desc`, `NAME_ASC`→`name-asc`, `NEWEST`→`newest` — enum member order} × filter variants {`plain` (no filters), `subject-language` (intent=`SessionIntent.Hifz`, language caller), `name-search` (search `"Teacher 000"` — matches the first hundred seeded name indexes deterministically), `min-rating` (floor `4`)} = **12 cells per volume**, default volumes {2000, 500, 100} → **36 cells**. Cell id: `matching-<volume>-<sortToken>-<variantToken>`. All browses: `page=1`, `pageSize=25` (wire defaults), locale `"en"`.
- **Volume windowing** (tasks.md 4.1): census = seed-scoped teachers satisfying the matcher's row-level eligibility (`is_online AND is_approved`, governance-free owner — the exact repo chain predicates), ordered by teacher id. A volume cell benchmarks the FIRST `volume` census teachers; teachers beyond the window are marked `is_online=false` (chunked ≤500-id updates) — cumulative in descending volume order, so each step flips only its delta, and **restored on every path** (`finally` restore; unit-proven for mid-run failure). Window facts (window size, flips, started-within-window, browsable estimate) land in the report's `windowing` section. Refusal: largest requested volume > census → exit 2 with the census count and the fix. NOTE (3.4-consistent): the census INCLUDES started-session teachers (row-level eligibility); at defaults the 100-teacher cell's browsable pool is ~92 (100 − 8 hot) — exactly the 3.4 evidence prediction.
- **Callers:** resolved deterministically from seeded students (id order): no-filter caller (primary/another language resolves to NO language filter — absent or Arabic-baseline) and language caller (non-Arabic token, `english` preferred — the seed's only non-Arabic student language). Any missing kind → prefix-stamped bench-owned insert (`perf_<id>_bench-caller-{baseline,english}@test.local`, funded balances, reuse of the manifest's per-run bcrypt hash) — removed by `perf:cleanup` through the prefix pattern. The service is called with REAL input shapes end to end (validation + caller resolution + filter build + repo read + envelope assembly) — no fabricated bypass.
- **Sampling** (specs REQ-2.3): per cell ≥5 warmup (default) then ≥30 samples (default) via `performance.now()`; warmup durations are never recorded, but a FAILED warmup browse is recorded as an error sample (fail-closed warmup). Per-cell p50/p95/p99/max/errorCount via the 1.1 `summarizeSamples` (integer-first nearest-rank).
- **Per-sample oracles (REQ-2.5/2.6):** every sampled call asserts (a) envelope consistency — `page===1`, `pageSize===25`, `pageCount===ceil(total/pageSize)`, slice length `min(pageSize, total)`; (b) **INV-A3 exclusion** — no teacher id holding a `started` session (seed-scoped oracle, queried once per run) appears in the result items. A violated oracle / thrown browse / broken clock (NaN or backwards) marks that sample `ok:false` with a stable `errorCode` (raw messages never stored); error samples count into the cell's `errorCount`.
- **Gate** (specs REQ-2.4/2.7 + 3.4 binding carry-forward): one gate per **volume===100 cell** — `evaluateGate(cellSummary, {id, p95MaxMs: gateMs, maxErrorCount: 0})`: p95 STRICTLY below the budget (exactly-at-limit FAILS), errorCount must be 0, zero samples fail closed. Non-100 volumes contribute report rows only (scale evidence). Self-check: gates `[]` → vacuous PASS. Verdict via the 1.1 `emitVerdict`; exit non-zero on FAIL.
- **Seed coordination** (2.1/2.2 contracts): newest **completed** seed manifest under `logs/perf/` (2.2's `listSeedManifestEntries`/`selectCleanupManifestEntry`/`validateCleanupManifest` reused; `completedAt: null` → exit 2 actionable refusal). Every query/write is scoped to the escaped prefix pattern `perf\_<runId>\_%`.
