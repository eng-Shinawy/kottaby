## Finding 1 [HIGH] — dead pg_stat_activity sampler (load-api)

**Defect:** the real io's `samplePgActivity` (old `scripts/perf/load-api.ts:182-201`) was doubly dead:
- **(A) Wrong bind:** `WHERE datname = $1` bound the full `environment.databaseUrl` (the DSN) — `datname` is the bare database name, so the predicate matched zero rows.
- **(B) Wrong shape:** `queryDb` (`backend/db/client.ts:248`) returns a pg `QueryResult` (rows on `.rows`), but the sampler did `Array.isArray(rows) ? rows : []` — always `[]`, so `nonIdleCount` was structurally 0. Confirmed against the client's return contract in `backend/db/client.ts`.

**Fix:**
- `scripts/perf/lib/load-api-io.ts` — new exported pure sampler `samplePgActivityRows(dbName, query)` + `PgActivitySnapshot` / `PgActivityQueryFn` types + `PG_ACTIVITY_SNAPSHOT_ROW_CAP` (200, moved from the entrypoint). The sampler binds the **bare database name** and reads rows off the **pg QueryResult (`.rows`)**; any read failure observes `null` (recorded as a read failure by the tracker).
- `scripts/perf/load-api.ts` — `createRealIo.assertTarget` now captures the guard's resolved `dbName` (`assertTestDatabaseTarget` returns `{ ok: true; dbName }`), and `samplePgActivity` binds THAT — never the DSN. The dynamic `@/backend/db/client` import stays post-guard.
- `scripts/perf/load-api.test.ts` — new describe block `pg_stat_activity sampler seam (queryDb shape + bare db name)`, 3 tests: the fake now matches the REAL seam (a **QueryResult-like object with `.rows`**, not a bare array), proving (a) the `$1` bind is the bare `kottaby_test` name (never `postgres://…`), (b) rows/non-idle counts are read from `.rows`, (c) the 200-row cap binds and a failed read observes null. Existing `FakeApiIo.samplePgActivity` (line ~234) already returns the io-contract shape `{ rows, nonIdleCount }` — correct at its layer; the QueryResult-shaped fake was added for the new queryDb-level seam tests. Tier structure untouched; no test weakened.

**Impact on prior evidence:** the 6.2 evidence run's "DB idle at every sample" observation is an artifact of this defect — see the honesty corrections below.

## Finding 4 [LOW] — same-second run-directory TOCTOU

**Defect:** `openRunDirectory` (`scripts/perf/lib/report.ts:151-162`) did `existsSync` then `mkdirSync(recursive:true)` — two same-second invocations could both observe "absent" and share the unsuffixed run directory.

**Tests:** `scripts/perf/lib/report.test.ts` — new test "a fully-occupied same-second suffix ladder is climbed via the atomic-create EEXIST arm" pre-creates the unsuffixed name plus `-2`/`-3` for the current and next second stamps and asserts the opener lands on `-4` (tolerant of a second-boundary tick); existing collision/concurrency/pre-existing tests all still pass against the new mechanism.
