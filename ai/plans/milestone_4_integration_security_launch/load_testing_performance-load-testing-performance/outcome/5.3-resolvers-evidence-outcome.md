## Resolver Contract (as built — binding for 6.x)

```ts
// backend/graphql/pothos/billing/subscription.pothos.ts
export const SubscriptionPothosObject = gqlSchemaBuilder
  .objectRef<EnrichedSubscriptionReturnType>("StudentSubscription")   // canonical supertype — TS-level only, SDL unchanged
  .implement({
    fields: t => ({
      plan: t.field({                                        // key presence decides:
        resolve: async (parent, _args, ctx) => {             //   carried value → served as-is;
          if (parent.plan === undefined) {                   //   key ABSENT → single-row read;
            return PlanCatalogService.findById(parent.planId, ctx.locale);
          }
          return carriedPlanOrPlanNotFound(parent.plan, ctx); // carried null → localized PLAN_NOT_FOUND, never a re-read
        },
      }),
      auditEntriesCount: t.int({
        resolve: parent => parent.auditEntriesCount ?? SubscriptionAdminService.auditEntriesCount(parent.id),
        // (the carried type is `number` — null is untypeable from producers, so `??` == key presence; 0 is preserved)
      }),
      auditTrailPeek: t.field({                              // nullable field — carried null IS the answer:
        resolve: parent => {                                 //   a trail-less row answers null without a re-read;
          if (parent.auditTrailPeek === undefined) {         //   key ABSENT → single-row read
            return SubscriptionAdminService.auditTrailPeek(parent.id);
          }
          return parent.auditTrailPeek;
        },
      }),
      // every other field: byte-identical passthrough/serialization, order unchanged
    }),
  });

// module-scope helper (the plan resolver's carried-null arm)
async function carriedPlanOrPlanNotFound(plan: PlanReturnType | null, ctx: Context): Promise<PlanReturnType>
```

### SR-reconciled design decisions

1. **Carried-null `plan` → the localized `PLAN_NOT_FOUND` denial, not a masked re-read.** The plan's literal D4 form (`"plan" in parent ? parent.plan : fallback`) is uncompilable in this codebase: Pothos types a non-nullable field's resolver as `MaybePromise<T> = Promise<T> | T` (null excluded), TS `in`-narrowing does not strip `undefined`/`null` from optional members of an intersection, oxlint `no-unsafe-type-assertion` rejects the narrowing cast, and `@typescript-eslint/no-non-null-assertion` is an error. A `??`-fallback would violate D4 (carried null silently re-read, masking a broken batch). The implemented arm surfaces the SAME denial the single-row read itself gives for an unresolvable plan (`NotFoundError("PLAN", tErrors.planCatalog.planNotFound)` via `ctx.t` — the AGENTS-mandated translated direct-error channel, code `PLAN_NOT_FOUND`), reachable only from a hostile/truncated batch — the restrict FK keeps real rows from ever landing there. Adversarially locked: the chaos test feeds a carried `plan: null` through a spied producer and asserts `PLAN_NOT_FOUND` on the wire with ZERO `findById` calls.
2. **`auditEntriesCount` uses `??` (lint-mandated `prefer-nullish-coalescing`).** Sound: the canonical carried type is `number` — null cannot be carried, so `??` is exactly key-presence; the honest carried `0` is preserved (0 is not nullish).
3. **`auditTrailPeek` uses an explicit `=== undefined` guard (if-form).** Deliberately NOT `??`: a carried `null` peek (trail-less row) must answer null WITHOUT the single-row re-read — D4's carried-null rule verbatim, and the if-form keeps the lint rule out of range.
4. **objectRef generic widened** to `EnrichedSubscriptionReturnType` (canonical, from `@/backend/types`): the only cast-free way to read the carried members; a superset with all-optional fields, so every plain-row producer stays assignable (verified: tsgo clean across the repo, SDL byte-identical, all consumers green).
