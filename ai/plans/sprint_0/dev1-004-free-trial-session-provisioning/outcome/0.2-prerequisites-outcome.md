## 5. Carry-Forward Knowledge (gotchas discovered)

1. **`getServerTranslations` is single-argument** — the spec's `getServerTranslations(locale, "<namespace>")` notation is shorthand. Actual signature: `getServerTranslations(locale: string): Translations`. Namespace access is via property access on the returned `Translations` object (e.g., `.errorsTranslations.trialAlreadyGranted`). The DEV1-004 service code MUST use this pattern (same as `registration.service.ts` line 162).

2. **Registration service uses the `withTransaction(outerTx)` SAVEPOINT pattern** — the trial grant MUST be invoked inside this transaction (after `createRoleChild` for student role, before `toReturnType`). The `outerTx` is the 3rd positional arg of `registerUser(input, locale, outerTx?)`. The DEV1-004 provisioning service should accept `outerTx?` with the same shape and propagate `tx` to every repo call.
