  artifact `graphql.ts` will finally change) and flip the zero-references pin in
  `country-code-scalar.test.ts` (test name documents the expectation).
- **Codegen mapping:** frontend types for `CountryCode` fields will surface as `string`
  (not the `CountryCode` union) — matching the `DateTime → string` precedent; the dataset
  union stays the service/frontend-form authority.

  in tests; `coerceInputValue`/`coerceInputLiteral` utilities SWALLOW coercion errors
  (return `undefined`) while direct method calls throw the library error verbatim.
