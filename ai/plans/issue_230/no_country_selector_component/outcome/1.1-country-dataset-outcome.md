## 1. Summary

Implemented the committed, generated ISO 3166-1 alpha-2 country dataset and its generator, mirroring the `scripts/iana-timezone-generator/` precedent (module layout, CLDR loading, curation set, AUTO-GENERATED header, deep-import-only consumption). The generator is idempotent (byte-identical re-runs, sha256-verified) and emits:

- `COUNTRY_CODES` — `as const` tuple of **255 uppercase ISO alpha-2 codes** (sorted with `localeCompare`).
- `export type CountryCode = (typeof COUNTRY_CODES)[number]`.
- `COUNTRIES: Record<CountryCode, { en: string; ar: string; flag: string }>` — CLDR `en` + `ar` territory names and a regional-indicator flag emoji derived by codepoint math (`A → U+1F1E6`).

## 3. Curation decisions (visible in code, not just here)

`EXCLUDED_COUNTRY_CODES = { EU, EZ, QO, UN, XA, XB, XK, ZZ, IL }` — an explicit `ReadonlySet` (iana `EXCLUDED_TERRITORY_CODES` precedent, docblock-documented):
- `EU`/`EZ`/`QO`/`UN`/`ZZ` — CLDR exceptional-reservation / grouping codes, not ISO 3166-1 countries.
- `XA`/`XB`/`XK` — user-assigned codepoints (CLDR test codes, Kosovo) with no official ISO assignment.
- `IL` — repository-wide territory-curation precedent (`iana-timezone-generator/territories.ts:4`); `PS` **stays** in the dataset.

Numeric M.49 region keys and `-alt-*` variant keys are rejected by the anchored `^[A-Z]{2}$` shape filter before curation. A code missing from either locale hard-fails the generator (`Missing CLDR territory name for ${code}`) — fail-closed, never a silent gap.
