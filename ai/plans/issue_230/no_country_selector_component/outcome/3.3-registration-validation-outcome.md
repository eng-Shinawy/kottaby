4-Tier mapping of the new `country-code contract` block:

- **Tier 1 (branches + persisted pair):** `"EG"` → row carries `countryCode: "EG"` + `country: "Egypt"` (display name from the dataset, not the raw code); `"US"` proves the lookup is per-code, not hardcoded (`"United States"`); `""` → `COUNTRY_CODE_REQUIRED` with message **byte-equal to** `getServerTranslations(LOCALE).authTranslations.countryCodeRequired`; legacy `"Egypt"` → `COUNTRY_CODE_INVALID` with `t.countryCodeInvalid`; all rejections are single-entry `ValidationError`s on the `country` path.
- **Tier 2 (normalization + membership boundaries):** `"eg"`→`EG`, `" EG "`→`EG` (both persist `"Egypt"`); valid-shape non-members `"XX"`/`"AA"` → `COUNTRY_CODE_INVALID`; transport-tamper `null`/`undefined` country → `COUNTRY_CODE_REQUIRED` (service guard defends behind the GraphQL layer).
- **Tier 3 (fuzz):** 64 seeded-LCG payloads (mixed case/digits/padding/symbols/Arabic/flag-emoji alphabet, ~1-in-8 dataset members) folded sequentially through the service — every escape is a `ValidationError` whose entries are all `field: "country"` with codes in `{COUNTRY_CODE_REQUIRED, COUNTRY_CODE_INVALID}`; the valid slice must have fulfilled (`fulfilledRegistrations > 0`); sequential fold is deliberate (concurrent nested savepoints on the shared tx collide — documented in-test).
- **Tier 4 (BOPLA mass-assignment):** hostile extras (`countryCode: "RU"`, `isDeleted`, `suspended`, `suspendedPeriodDays`, `isBlocked`, `handshakeCode`) all ignored — persisted pair stays server-derived (`EG`/`Egypt`), governance defaults hold, student child row keeps a fresh `KSB-` handshake code ≠ the hostile value. All external channels stay mocked (suite-level fixtures).
