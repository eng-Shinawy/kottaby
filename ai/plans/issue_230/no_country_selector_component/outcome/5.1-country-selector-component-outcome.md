## Summary

`frontend/components/ui/CountrySelector.tsx` is a presentation-only MUI v9
`Autocomplete` over `COUNTRY_CODES`/`COUNTRIES` (deep imports from
`@/shared/constants/countries`). Option labels are the localized dataset names
(`COUNTRIES[code][locale]`, locale from `useAppLocale()`), the flag emoji renders
in `renderOption` **and** as a bare `startAdornment` in `renderInput`, the
own-copy (`placeholder`, `noOptionsText`) comes from the `countrySelector`
namespace, and every style goes through `sx` with logical properties
(`marginInlineEnd`, `textAlign: "start"`) so RTL needs no physical overrides.
The story (`Form/CountrySelector`) wraps the component in a controlled harness
with an ar/en toggle story set (Default / WithSelection / ErrorState / Disabled).

Prop contract — exactly the plan's signature:

```ts
{ id?: string; name?: string; label: string; value: CountryCode | "";
  onChange(code: string): void; onBlur?: () => void; error?: boolean;
  helperText?: ReactNode; required?: boolean; disabled?: boolean }
```

`label` stays a **required prop** (per the same task's prop list) so the
component holds no view-specific copy; the story harness supplies it from
`t.fieldLabel`, which is how the plan's `fieldLabel` requirement is honored
without hardcoding UI text inside the component.

Key implementation details verified against the spec:
- Aliased namespace import avoiding the component-name collision:
  `import { CountrySelector as CountrySelectorNs } from "@/shared/locale/namespaces/countrySelector"` (4.1 carry-forward, plan-review-R1 F-12).
- `slotProps` **merge-not-replace** (WalletPickerHeader.tsx pattern): spreads
  `...params.slotProps`, then `htmlInput: { ...params.slotProps?.htmlInput, name, "aria-label": label }`
  and chains the consumer `onBlur` **after** MUI's own handler (form blur hooks
  keep working alongside popup-close blur). Never `inputProps`.
- Bare `startAdornment` (RegisterIdentityFields.tsx:41 pattern): flag emoji in a
  decorative `span`, or `PublicOutlined` (v9 `*Outlined` naming) when nothing is
  selected; tinted via `var(--mui-palette-action-active)` — same CSS-var-palette
  pattern as the register form, no hardcoded colors anywhere.
- `formHelperText: { "aria-live": "polite" }` + `aria-invalid={error}` on the
  TextField (repo accessibility convention, `RegisterIdentityFields.tsx`).
- `getOptionLabel`/option rows read `COUNTRIES[code]` only with dataset member
  codes — no computed-key surface.

## 5.1.TE — Test Engineering (4 tiers, all in the colocated test)

`bun run test/scripts/run-test.ts frontend/components/ui/CountrySelector.test.tsx`
→ **14 pass / 0 fail / 1272 expect() calls** (re-run after the QL fixes).

The repo has **no DOM component-test layer** (no happy-dom/jsdom, no DOM
testing utilities) and **no automated story runner** (see below), so the suite
replaces the MUI Autocomplete boundary with a render-through double via
`mock.module("@mui/material")` (mechanism precedent: rateTeacherMutationError
module-mock ordering contract) and renders through real `TextField` +
`renderToStaticMarkup`, exercising the component's actual
options/getOptionLabel/renderOption/renderInput code paths.

- **Tier 1 (render + contract):** namespace label/placeholder render; stub
  receives exactly `COUNTRY_CODES`; every code rendered as `role="option"` with
  localized name + flag; `onChange` fires with the ISO code (`"EG"`, `"SA"`) and
  with `""` on clear; controlled value maps to the display name and marks the
  row `aria-selected="true"`.
- **Tier 2 (boundaries):** empty value keeps placeholder and no selection;
  `error`+`helperText` render with `aria-invalid="true"` and polite live region;
  RTL (`dir="rtl"` container, ar locale) renders Arabic copy, flags, logical
  `text-align:start` / `margin-inline-end` and no physical `text-align:right`
  (static proxy for "flag not clipped" — no layout engine in bun:test);
  `disabled` forwards to Autocomplete and input, markup non-interactive.
  Extras: slotProps merge keeps MUI's endAdornment while adding
  label/name/startAdornment; consumer onBlur chained after MUI's (and passes
  through untouched when absent).
- **Tier 3 (fuzz):** 200-round seeded-LCG rapid re-render + concurrent onChange
  emissions under `Promise.allSettled` — all fulfilled, every emitted value is
  `""` or a dataset member.
- **Tier 4 (injection):** hostile helperText renders React-escaped
  (`&lt;img …&gt;`), no raw `<img`, no `dangerouslySetInnerHTML` in markup **or
  component source** (file scan); options are exactly the dataset —
  `__proto__`/`constructor`/`prototype`/`toString`/`hasOwnProperty` absent,
  every option a dataset member, and `getOptionLabel` on hostile keys returns
  `undefined` without throwing.
