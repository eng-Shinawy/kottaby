   substring pin is stricter (it also locks argument order) and covers the same contract.

   SERVER process, so the `NotificationEngineCallOptions` transport seam is unreachable from
   the test process; the fan-out publish degrades gracefully (logged, never failing the
   request) — the persist-first row oracle is the wire-visible guarantee. Envelope-level fanout
   proof remains covered by the journey/task-2.1 `SpiedFanoutTransport` assertions at the
   service tier.
