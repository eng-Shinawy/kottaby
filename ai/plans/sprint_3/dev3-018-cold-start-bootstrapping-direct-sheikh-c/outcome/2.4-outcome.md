## Deviations

1. **Spy assertions are delta-based, not absolute.** Bun's `spyOn(logger, "logDomainError")`
   reuses the same underlying mock across tests in one file and `mockRestore()` does not clear
   accumulated call history (first run: counts 2,3,4,… across tests, 6 failures). Fixed by
   asserting `calls + 1` / `calls` against a pre-call baseline and reading the context via
   `spy.mock.calls.at(-1)`. Behavior under test unchanged.
2. **Governance re-read instead of gate-internal row reuse.** `assertActorAdmin` returns `void`
   and is locked byte-parity, so it cannot hand back the actor row. `assertActorAdminActive`
   performs one follow-up `UserRepository.findById(actorId, outerTx)` after the role gate
   passes, strictly before any governance decision and only on the pass path; on every denial
   path there are ZERO reads/writes past the point of denial. This satisfies both the
   byte-parity (2.4.SEC) and single-gate-source (2.4.SR) constraints simultaneously.
3. **Chaos suite count**: the task text cites "61 + 3 suites"; the live chaos file contains 8
   tests. Recorded as a stale plan figure; both regression locks are green regardless.
