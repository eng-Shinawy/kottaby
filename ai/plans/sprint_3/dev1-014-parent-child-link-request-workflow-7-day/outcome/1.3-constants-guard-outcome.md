## 5. Security & Tenancy Audit (1.3.SEC)

- **Guard purity:** `isLinkStatus` takes `value: unknown` and performs only `typeof value === "string"` + `Object.values(LinkStatus).includes(value)`. NO I/O, no network, no DB, no globals, no `console.*`, no module-level mutable state (`Object.values` materializes a fresh array per call — no aliasing/shared-buffer surface). Deterministic: same input ⇒ same result.
- **Fail-closed by construction:** anything that is not a `string` is rejected on the first conjunct; any string not EXACTLY equal to a member value is rejected on the second; the function CANNOT throw for any input (no property access on `value` — prototype pollution payloads, `Symbol`, functions, exploding-`toString` objects are inert; all proven by Tier 4). There is no "allow by default" path: the only `true` lane is exact membership in the four-value enum.
- **Type-predicate safety:** `value is LinkStatus` narrows only after the membership proof, so a `true` can never smuggle a non-member through downstream code (the 2.x read-mapping boundary consumes exactly this guarantee for corrupt stored statuses).
- **Constants:** pure arithmetic, no env reads, no secrets/PII, no injection surface. A wrong `PARENT_LINK_REQUEST_MS` could only shorten/lengthen the request window — the DB-partial-unique and guarded-UPDATE arbiter lands in 2.x are independent of its value.
- **Tenancy:** no actor/tenant surface at all — pure value-level vocabulary.
