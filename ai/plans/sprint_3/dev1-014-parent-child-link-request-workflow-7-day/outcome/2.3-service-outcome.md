## Service contract (delivered verbatim per plan §4.2)

- `requestLink(code, parentActorId, locale, outerTx?, options?)` → `OutgoingParentLinkRequestReturnType | null` — normalize PRE-DB (`ValidationError(t.handshakeCodeInvalid)`); governance-excluded/missing ⇒ `null` (zero rows/publishes); `PARENT_LINK_TARGET_ALREADY_LINKED`; `PARENT_LINK_ALREADY_PENDING` (pre-check + 23505 cause-chain via `isUniqueViolation` — same conflict); recipient locale via `findLocalesByIds` + `defaultLocale` fallback; in-tx `emitForUser` (`relatedEntityType: "parent_link_request"`); `publishReceipts` OWN-COMMIT only; `maskFullName` on outgoing.
- `respondToLinkRequest(requestId, accept, studentActorId, locale, outerTx?, options?)` → `IncomingParentLinkRequestReturnType` — guarded claim; classifier: nonexistent ≡ foreign ⇒ byte-equal `NotFoundError("PARENT_LINK_REQUEST")`; non-pending ⇒ `PARENT_LINK_REQUEST_ALREADY_RESOLVED`; pending-but-dead ⇒ `markExpiredIfPending` + `PARENT_LINK_REQUEST_EXPIRED`; accept=true ⇒ `linkParentIfUnlinked` (null ⇒ `PARENT_LINK_TARGET_ALREADY_LINKED`, whole-tx rollback — no ghost confirmation) → `expireSiblingPendingsForStudent` → accepted notify to parent in parent's persisted locale; accept=false ⇒ rejected notify, no students write, no sibling expiry.
- `cancelLinkRequest(requestId, parentActorId, locale, outerTx?)` — silent withdrawal (ZERO notifications), fold to `rejected`, return via `findOutgoingRowById`.
- `listMyOutgoing` / `listMyIncoming` — self-scoped on the VERIFIED actorId; computed `Expired` render WITHOUT writing (read purity, REQ-015); `isLinkStatus` fail-closed.
- Actor re-check (every op): fresh `UserRepository.findById`; id≤0/missing ⇒ `UnauthorizedError`; role mismatch / `isDeleted||isBlocked||suspended` ⇒ `ForbiddenError` (constant copy). Each denial = ONE `logDomainError { code, entity, entityId?, locale }` — no names/emails/codes (orchestrator-verified by direct inspection of all log sites).
