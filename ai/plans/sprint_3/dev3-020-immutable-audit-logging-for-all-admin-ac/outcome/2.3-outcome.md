- Signatures to call:
  - `AuditTrailRepository.listEntries(filters, limit, offset, tx?)` → `Promise<AuditTrailEntryRow[]>` — `limit`/`offset` are the resolved pagination (`pageSize`, `(page-1)*pageSize`); newest-first ordering is IN the repo; out-of-range offset → `[]` (pair with `countEntries` for the honest `totalCount`).

- The repo performs NO validation, NO error mapping, NO logging: every failure path (gate, filter validation, pagination clamps, corrupt stored enum) is the service's.
