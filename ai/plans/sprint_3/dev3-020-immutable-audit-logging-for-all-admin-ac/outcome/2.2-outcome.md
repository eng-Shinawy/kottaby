## 3. Gate repair (the only functional edit to the inherited file)

The sub-loop gate initially FAILED (exit 1) — the inherited file carried 3 oxlint `typescript(no-unsafe-enum-comparison)` warnings at lines 379–381 (`fixtureRows.find(row => row.actionType === AuditActionType.Override|Adjust|Suspend)`): the insert-returning rows type `actionType` as the raw stored string union, while the right operand is the enum object. Two-step repair within THIS file only:

1. First attempt (`String(AuditActionType.X)`, the lint's own hint) was itself flagged — `typescript(no-unnecessary-type-conversion)` ×3 ("expression already has type 'AuditActionType.Override'"). Rejected.
2. Final fix: module-scope widening helper `rawActionType(actionType: AuditActionType): string` (enum members are string subtypes — implicit widening, no explicit conversion) + a production-language comment explaining that the raw stored value is the fixture lane's business because coercion is the read service's job. All three warnings cleared; test behavior byte-equivalent (same rows found, same assertions).
