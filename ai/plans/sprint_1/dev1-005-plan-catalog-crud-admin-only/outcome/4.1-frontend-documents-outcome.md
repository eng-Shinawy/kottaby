## Finding worth propagating (for 4.2 consumers)

`codegen.ts` runs with `avoidOptionals: true`, so optional GraphQL INPUT fields are emitted as
**required keys typed `| null | undefined`** (not `?`-optional):
`UpdatePlanInput = { currency: string | null | undefined; intervalDays: number | null | undefined; … }`.
A partial patch therefore keeps untouched keys `undefined` (JSON serialization drops them ⇒ never
sent; the server's defined-and-non-null builder also normalizes explicit `null`). Variables types
keep normal optionality for nullable variables (`includeInactive?`). tsgo caught my first test
draft using the wire-style `{ price: "9.99" }` literal (TS2739) — fixed in-file.
