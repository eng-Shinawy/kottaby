### 1.2 Tooling limitation — NO branch metrics exist in this toolchain (documented)

- Bun **1.3.14** text reporter (`--coverage`) prints exactly two numeric columns per file; the header labels them `% Funcs | % Lines`. There is **no branch column**.
- Bun's `--coverage-reporter=lcov` output was inspected for both target files: **zero `BRDA`/`BRF`/`BRH` records** (`grep -c BRDA lcov.info` → `0`). Bun 1.3.x does not emit branch instrumentation data for TS.
- Therefore per-file **branch coverage cannot be measured** in this sandbox. Per the task contract, the closest achievable measurement was run (line + function coverage via both the text table and lcov) and **every branch was mapped to a dedicated, passing test** (§1.4). No assertion was weakened anywhere.
