## SR (self-review) findings

1. **`$all` conjunction** re-verified against the engine docs and the applicant precedent before writing; plain map rejected (ANY-semantics trap).
2. **`nullable: false` on a list field** yields `[Plan!]!` in Pothos (list non-null + items non-null) — matches REQ-016/030; no `null` can leak from the resolver (service returns arrays).
3. **`args.includeInactive ?? true`** kept even though the SDL default fills omitted args: it hardens the explicit-null path and satisfies the plan's nullable-hardened handling requirement. tsgo/biome/oxlint accept it (no unnecessary-?? rule triggered).
4. **Test id typing**: `ID` scalar serializes to string on the wire; fixture comparisons use `String(plan.id)` — no implicit-any, no unsafe assertions.
5. **Apollo Client v4 deprecation trap**: explicit generics on `client.query<TData, TVars>(...)` select the DEPRECATED overload (`_INFERENCE_ONLY_DO_NOT_SPECIFY` guard) and type-aware lint fails with `sonarjs/deprecation` warnings-as-errors. Solved the sanctioned way: documents annotated as `TypedDocumentNode<TData, TVars>` via TYPE-ONLY import from `@apollo/client`, so inference flows from the document. (`parse`'s `DocumentNode` is structurally assignable because the marker prop is optional — no casts.)
