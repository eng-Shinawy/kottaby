## 4. Audit findings + fixes applied (diff-level)

4. **FIX (test) — oxlint `no-await-in-loop` ×5** in the Tier-2 matrix loops (sessionCount, price, currency, and the dual id loop). Converted each `for…of` + `await expectValidationError(...)` into `Promise.all([...].map(...))` with `toHaveLength` guards. Same-tx concurrent queries are proven safe by the Tier-3 `allSettled` tests; `expectValidationError`/`expectRepoError` never reject (they catch and return), so `Promise.all` cannot mask a rejection.

Non-findings worth recording: `backend/lib/errors.ts` `ConflictError(code, message)` overload already present (0.3 gate item landed before this run — verified by reading the class); zero `{ ...input }` / `{ ...patch }` spreads reach DB calls (grep: only key-by-key conditional spreads); no cross-table imports (imports are exactly: `@/backend/db/repo`, `@/backend/lib/errors`, `@/backend/lib/logger`, `@/backend/types`, `@/shared/locale/server-graphql`); no dead code; comments carry zero REQ/Task/Phase tokens (the DEV3-020/D1 audit-seam marker is the amended 2.3.7-mandated comment).
