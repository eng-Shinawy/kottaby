# Void
![](https://d24lr4zqs1tgqh.cloudfront.net/1036d68e-bd75-4d9a-af07-0699dcea11fd-696e9edc0acf4f5a50bce69f.svg)

**Who is this for** \- Product managers, business owners, and stakeholders who need a high-level overview of void transactions and how they are handled through Paymob

**Outcome -** Understand what void transactions are, when to use them, and how to initiate voids using the Paymob Dashboard.

* * *

## What is a Void Transaction?

A void cancels a successful payment **before settlement**. Since the transaction is stopped early in the process, the funds are not transferred to the merchant, and the customer does not receive a separate refund. Mostly, it will be available on the same business day, before settlement occurs.

![](https://d24lr4zqs1tgqh.cloudfront.net/3d1c3582-3b5e-40d4-8e00-3330caca54b7-696e9edc0acf4f5a50bce69f.svg)

### Common Use Cases

Voids are typically used when a customer cancels immediately after checkout

![](https://d24lr4zqs1tgqh.cloudfront.net/2e2f5246-1eca-4263-943d-b4ce391489c0-696e9edc0acf4f5a50bce69f.svg)

### Payment methods that void is supported for:

Card payment method only

### Dashboard Void

###### 1

Select the successful **card** transaction you want to **void**

###### 2

Click the **Void** button, which will show the void pop-up

###### 3

Click the **Void** button in the void pop-up
