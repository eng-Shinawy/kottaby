# Getting Integration Credentials
![](https://d24lr4zqs1tgqh.cloudfront.net/47f9d75c-6a0b-4c07-82b9-831c16161b22-696e9edc0acf4f5a50bce69f.svg)

**Who is this for:** Anyone can implement the integration

**Outcome:** Get the Paymob credentials that will be used during the integration

* * *

### Overview

When you integrate with Paymob, even through APIs, Plugins, or Mobile SDKs, you'll need to use some of your Paymob credentials (e.g., secret key, public key, API key, …).

### How to get each credential

#### Secret Key

  - Go to your "**Accept Dashboard** ", then click on the "**Settings** " tab

  - Make sure that you have enabled the appropriate mode (**live** /**test**) according to the Integration ID(s) that will be used.

  - Press the View button beside the **secret key** , then copy the key value that will appear as shown in the screenshots below.

![](https://d24lr4zqs1tgqh.cloudfront.net/347e91c5-7c65-40f2-9ca4-9728d05b1e9a.jpg)

![](https://d24lr4zqs1tgqh.cloudfront.net/9bc72784-304c-4815-a247-61085ea5f9a0.jpg)

* * *

#### **Public Key**

  - Go to your "**Accept Dashboard** ", then click on the "**Settings** " tab

  - Make sure that you have enabled the appropriate mode (**live** /**test**) according to the Integration ID(s) that will be used.

  - Press the View button beside the **public key** , then copy the key value that will appear as shown in the screenshots below.

![](https://d24lr4zqs1tgqh.cloudfront.net/91d43486-01b1-4308-85f7-48965b93455c.jpg)

![](https://d24lr4zqs1tgqh.cloudfront.net/058d6a52-da57-41a4-a85d-f798a78ac82b.jpg)

* * *

#### API Key

  - Go to your "Accept Dashboard", then click on the "**Settings** " tab.

  - Press the **View** button beside **API key** , then copy the key value that will appear as shown below.

![](https://d24lr4zqs1tgqh.cloudfront.net/5c956737-f697-410a-977c-88734189628b.jpg)

> **Info:**
> 
> It's the same key for both environments (**Test/Live**)

* * *

#### Get the Integration ID(s)

  - Go to your "**Accept Dashboard** ", then click on the "**Developers** " tab ⇒ "**Payment Integrations** " tab.

  - Make sure to select the proper mode (**Test/Live**).

![](https://d24lr4zqs1tgqh.cloudfront.net/f2b00c83-0174-4483-8b7d-ef198c7157d8.jpg)

![](https://d24lr4zqs1tgqh.cloudfront.net/c4fdfcea-725d-4458-966c-8e4a333b707c.jpg)

* * *

### Change Callback for the Integration IDs

  - Go to your "Accept Dashboard", then click on the "Developers" tab >> "Payment Integrations" tab.

  - Make sure to select the proper mode (**Test/Live**).

  - Select the Integration ID.

  - Press the **Edit** button.

  - Fill in the **callback URLs**.

  - Press the **Submit** button.
